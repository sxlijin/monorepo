# fastlane — App Store metadata

> Note: `fastlane/README.md` is auto-generated by fastlane on every run. Keep human docs here.

This manages the App Store listing (text fields + screenshots) as files, pushed to
App Store Connect with one command. It does **not** upload the app binary — archive and
upload that from Xcode (Product → Archive → Distribute App).

## One-time setup

1. Install the tooling (uses the repo `Gemfile`):
   ```bash
   bundle install
   ```

2. Create an **App Store Connect API key**: App Store Connect → Users and Access →
   Integrations → App Store Connect API → generate a key with **App Manager** access.
   Download the `.p8` (you can only download it once) and note the **Key ID** and **Issuer ID**.

3. Put the key somewhere outside git and export the env vars (the `.p8` is gitignored):
   ```bash
   cp ~/Downloads/AuthKey_XXXXXXX.p8 fastlane/AuthKey.p8
   export ASC_KEY_ID=XXXXXXXXXX
   export ASC_ISSUER_ID=xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx
   # optional: export ASC_KEY_FILEPATH=/some/other/path/AuthKey.p8
   ```

## Edit the listing

Each field is a plain `.txt` file under `metadata/`:

| Field | File |
|---|---|
| Subtitle | `metadata/en-US/subtitle.txt` |
| Promotional Text | `metadata/en-US/promotional_text.txt` |
| Description | `metadata/en-US/description.txt` |
| Keywords (comma-separated, ≤100 chars) | `metadata/en-US/keywords.txt` |
| What's New | `metadata/en-US/release_notes.txt` |
| Support URL | `metadata/en-US/support_url.txt` |
| Marketing URL (optional) | `metadata/en-US/marketing_url.txt` |
| Privacy Policy URL | `metadata/en-US/privacy_url.txt` |
| Category | `metadata/primary_category.txt` |
| Copyright | `metadata/copyright.txt` |
| Reviewer contact / notes | `metadata/review_information/*.txt` |
| Screenshots (6.7", 1284×2778) | `screenshots/en-US/*.png` |

### Must fix before submitting (search for `TODO`)
- `support_url.txt` and `privacy_url.txt` — real, reachable URLs (required by review).
- `review_information/{first_name,last_name,phone_number}.txt` — your contact info.
- **App name** is managed here (`name.txt` = "Barcodes by Sam"). `fastlane metadata` will set
  the App Store name to this value, so it must match the name reserved in App Store Connect (or
  be an available name). Edit `name.txt` to change it.

### Length limits
name ≤30 · subtitle ≤30 · promotional text ≤170 · keywords ≤100 · description ≤4000

## Push to App Store Connect

```bash
bundle exec fastlane metadata        # uploads text + screenshots (no binary)
```

`metadata` leaves `submit_for_review: false`, so it updates the listing without submitting.
Review the app in App Store Connect, then submit (or flip `submit_for_review` in the Fastfile).

List the metadata files without uploading:
```bash
bundle exec fastlane metadata_verify
```
